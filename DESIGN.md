## Brand & Style

This design system serves high-concurrency enterprise logistics, postal administration, and parcel transit platforms. Built on the solid engineering foundation of Ant Design, it integrates China Post's authoritative visual identity to deliver precision, efficiency, and steadfast reliability.

The visual style adheres to **Corporate / Modern**:

- **Clarity & Information Density:** Standardized table densities, high-legibility typographic scale, and optimized visual contrast tailored for logistics tracking and back-office management.
- **Brand Resonance:** Grounded in authentic China Post Green (`#0F6B3D`) with tiered functional accents, maintaining calm authority without visual clutter.
- **Determinism:** Predictable interactions, explicit feedback, and uniform spatial rhythms engineered for desktop enterprise applications.

## Colors

The color palette is rooted in China Post's standard green hierarchy, augmented by operational alert tokens and structural neutral surfaces.

- **Primary Green (`#0F6B3D`)**: The primary brand driver, used for key actions, selected states, and active focal elements. Supported by hover (`#148A4E`), active (`#083B21`), light backgrounds (`#EAF6EE`), and perimeter borders (`#BCE2C9`).
- **Functional Semantics**: Standard status feedback mapped directly to operational indicators—Success (`#00B578`) for normal dispatch/delivery, Warning (`#FA8C16`) for delays, Error (`#F5222D`) for anomalies and exceptions, and Info (`#1677FF`) for order navigation links.
- **Neutrals & Containers**: Grounded on pure white (`#FFFFFF`) card surfaces, warm-tinted neutral backgrounds (`#F4F6F8`), and three tiers of text hierarchy (`#1D2129`, `#666F80`, `#9E9E9E`) paired with crisp border outlines (`#E5E6EB`).

## Typography

The typographic stack is engineered to resolve cross-platform character rendering gaps across macOS, Windows, Linux, and mobile clients, guaranteeing that no glyph fallback fails.

### Font Family Stacks

1. **System Default UI & Modern Sans-serif (Default)**:
   `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', '微软雅黑', 'Noto Sans SC', 'Alibaba PuHuiTi', sans-serif`
   Used across all display, headline, title, and body tokens. Provides crisp CJK ideographs and matching Latin numerals on Windows (ClearType YaHei), macOS/iOS (苹方), and custom Linux distributions (思源黑体).

2. **Monospace & Tabular Numerals (`number-data` & `code`)**:
   `'SF Mono', Consolas, 'Liberation Mono', Menlo, 'Courier New', monospace`
   Enforced for tracking numbers (waybill IDs), postal codes, vehicle telemetry data, coordinates, and timestamp streams.
   **Critical Implementation Rule:** Always configure `font-feature-settings: "tnum"` and `font-variant-numeric: tabular-nums` globally across all grid headers, status values, and numerical displays to ensure vertical column alignment across changing digits.

3. **Serif & Formal Documents (`editorial-title`)**:
   `'Songti SC', 'Source Han Serif SC', 'SimSun', 'STSong', serif`
   Reserved for formal administrative notices, official decrees, charter seals, and postal certificates.

## Layout & Spacing

The layout model is anchored to Ant Design's 24-column grid system with a standard base grid unit of 4px.

- **Grid & Gutters**:
  - Desktop standard gutter is `16px`, expanding to `24px` for high-resolution operations control centers.
  - Page canvas margin is fixed at `24px` on desktop, scaling down to `16px` on tablet views.
- **Rhythm & Padding**:
  - `space-xs` (4px): Inline indicator spacing, badge paddings, and tight element gaps.
  - `space-sm` (8px): Button icon-to-text spacing, compact table cell vertical paddings.
  - `space-md` (12px): Standard form element gap, filter row margins.
  - `space-lg` (16px): Card internal header-to-body spacing, list item gutters.
  - `space-xl` (24px): Card exterior spacing, dashboard widget margins, modal perimeter padding.

## Elevation & Depth

Visual hierarchy relies primarily on **tonal containment** and **low-contrast outlines**, supplemented by restrained ambient drop shadows for overlay layers.

- **Level 0 (Flat / Canvas)**: Background workspace color `#F4F6F8` with no elevation.
- **Level 1 (Card & Content Blocks)**: Surface `#FFFFFF` encased in a crisp `#E5E6EB` 1px border. No drop shadow is applied in default states to keep high-density dashboards clean.
- **Level 2 (Hover & Active Surfaces)**: Subtle ambient lift on interactive cards: `box-shadow: 0 2px 8px rgba(0, 0, 0, 0.08)`.
- **Level 3 (Dropdowns & Popovers)**: Floating navigation menus and selects use `box-shadow: 0 4px 16px rgba(0, 0, 0, 0.12)` with a 1px `#E5E6EB` boundary.
- **Level 4 (Modals & Drawers)**: High-priority operational dialogs use `box-shadow: 0 6px 24px rgba(0, 0, 0, 0.16)` centered over a 45% dark backdrop.

## Shapes

The design system maintains a unified border-radius standard of **6px (Default / Level 2)** for common interactive components, balancing modern softness with business rigor:

- **Sharp (`0px`)**: Full-bleed table header rows and split-pane dividers.
- **Small (`2px - 4px`)**: Checkboxes, status indicator pips, and code badges.
- **Default (`6px`)**: Primary/secondary buttons, input controls, select pickers, and tab segments.
- **Large (`8px - 12px`)**: Modals, alert banners, cards, and notification panels.
- **Full (`9999px`)**: Status tags, VIP badges, counter capsules, and avatar containers.

## Components

### 1. Buttons

- **Primary**: Solid China Post Green (`#0F6B3D`) background with white text. Height is `32px` standard (or `40px` large). Hover transitions to `#148A4E`, and active click compresses to `#083B21`.
- **Default**: White background with `#E5E6EB` border and `#1D2129` text. Hover shifts border and text to `#148A4E`.
- **Danger**: Red (`#F5222D`) tone for irrevocable operations (e.g., cancelling batch manifests).
- **Workbench size**: Query forms, table toolbar actions (刷新 / 新建 / 重置 / 重试) inherit `VITE_FORM_CONTROL_SIZE` (`small` / `middle` / `large`, default `large` / `40px`). Do not force a different size on these actions.
- **Link actions**: Table row 查看 / 编辑 / 删除 stay `link` and follow `body-md` (`14px`), not a separate button size.

### 2. Input & Select Controls

- Standard height is `32px` with `4px 11px` inner padding. Border uses `#E5E6EB`.
- On focus, border transitions to `#0F6B3D` and renders a 2px diffuse glow (`rgba(15, 107, 61, 0.2)`).
- Prefix and suffix icons are rendered in `#9E9E9E`.

### 3. Forms

- Workbench add/edit forms **always** use Ant Design Form `layout="horizontal"`. Do not use `vertical` or `inline` in Modal forms.
- Label sits to the **left** of the control, right-aligned, width `120px`, with a colon. The control takes the remaining width (`labelCol={{ flex: "120px" }}`, `wrapperCol={{ flex: "auto" }}`, `labelAlign="right"`, `colon`).
- Modal forms inherit `VITE_FORM_CONTROL_SIZE` (default `large` / `40px`). One field per row — do not drop two `Form.Item`s into a CSS grid that fights the label column. Do not hardcode `size="large"` on page forms.
- Query toolbars are a single row of inputs, not a Form layout. Read-only view uses `ViewFields` (label `112px` left), not a disabled Form.
- Import Form from `src/components/Form`. Pages must not set `layout="vertical"`.

### 4. Tables & Data Grids

- Use Ant Design Table `middle` density. Header and body share one type size: `body-md` / `14px / 20px`. Do not mix `small` (12px) cells with `large` toolbar controls.
- Headers use background `#FAFAFA` with `#666F80` semi-bold text (`title-sm`, still `14px / 20px / 600`).
- Body text is `#1D2129`. Secondary cells (IDs, timestamps, nodes) use `#666F80` at the same `14px` — change color only, never shrink the type.
- Numeric columns (tracking IDs, postage costs, transit hours) must strictly employ `code` or `number-data` tokens paired with `tabular-nums` to guarantee vertical decimal and digit alignment.
- Status chips inside cells stay `body-sm` (`12px`, height `22px`); they are the only smaller type in a row.
- **Row actions**: 查看 / 编辑 / 删除 / 查看轨迹 / 重新归档 are `link` text at `body-md` (`14px`) with a 14px leading icon and a persistent underline (`text-decoration: underline`, offset `2px`). Icon-to-label gap is `4px`; consecutive actions are spaced `16px` apart. Do not render these as chips or solid buttons.
- **Action colors are fixed** (each verb keeps its own hue; 查看 must not share 编辑’s color):
  - 查看: Info `#1677FF`, hover `#4096FF`, Eye icon.
  - 编辑: Primary `#0F6B3D`, hover `#148A4E`, Edit icon.
  - 删除: Error `#F5222D`, hover `#FF4D4F`, Delete icon.
- **Action column width is fixed** so rows do not reflow: 1 action `104px`, 2 actions `216px`, 3 actions `240px`, 4 actions `300px`. Right-align, `nowrap`. Never omit `width` on the 操作 column.
- Row zebra striping is optional; hover row background is `#EAF6EE` at 50% opacity.

### 5. Pagination

- Use Ant Design Pagination **default** item style. Do not invert the current page into a solid primary fill that hides the page number.
- Current page: primary border + primary text on white (`#FFFFFF` / `#0F6B3D`). Other pages: `#1D2129` text on white with `#E5E6EB` border.
- Total count and size changer use `body-md` (`14px`) and `#666F80`. Active number must remain readable (contrast ≥ 4.5:1).

### 6. Status Tags

Use the shared Form `Status` wrapper around Ant Design [Tag](https://ant.design/components/tag-cn). Do not hand-roll pills, and do not pass raw `color="green"` / `orange` / `red`. Only these five tones:

| Tone           | Ant Design `color` | Use for                           |
| -------------- | ------------------ | --------------------------------- |
| **success**    | `success`          | 已签收、启用、正常、密钥启用      |
| **processing** | `processing`       | 运输中（含揽收后在途）、P3 低异常 |
| **warning**    | `warning`          | 退回、P2 中异常、中风险、滞留提示 |
| **error**      | `error`            | 撤单、P0/P1、锁定、冻结、高风险   |
| **default**    | `default`          | 待揽收、无异常、停用、一般风险    |

Fixed maps:

- **运单**: 待揽收 `default` · 运输中 `processing` · 已签收 `success` · 退回 `warning` · 撤单 `error`
- **异常等级**: 无/`NONE` `default` · P3 `processing` · P2 `warning` · P0/P1 `error`
- **账号**: 启用 `success` · 停用 `default` · 锁定 `error`
- **客户**: 正常 `success` · 冻结 `error`
- **客服组 / 密钥**: 启用 `success` · 停用 `default`

Pill radius `full`, type `body-sm` (`12px`), height `22px`. VIP remains gold `#FFF7E6` / `#D48806` as a separate badge, not a status tone.

### 7. Checkboxes & Radio Buttons

- Default 16px square/circle with `#E5E6EB` border.
- When checked, fills with `#0F6B3D` and displays a crisp white mark.

### 8. Cards & Modals

- **Card**: Surface `#FFFFFF`, border radius `8px`, 1px border `#E5E6EB`, padding `24px`.
- **Modal**: Surface `#FFFFFF`, border radius `12px`, padding `20px 24px`, title styled with `title-lg` (`18px / 600`). Widths: small `416`, medium `640`, large `880`, xlarge `1200`.
- **Waybill timeline**: Use the shared Form `Modal` at size `xlarge` (`1200px`). Title `title-lg` (`18px / 600`). Section labels, node titles, org names, timestamps, and descriptions use `body-md` (`14px / 20px`). Status chips and duration capsules stay `body-sm` (`12px`). Do not use 10px or 11px, and do not hand-roll a drawer overlay.

### 9. Sidebar Navigation

- Width `256px` expanded, `64px` collapsed. Surface `#FFFFFF`, right border `#E5E6EB`. Sits under the `64px` header.
- Brand row uses the 7×7 primary mark and `title-sm` (`14px / 600`) label「业务导航目录」. Do not use 12px here.
- Menu items are `40px` tall, radius `6px`, `body-md` (`14px / 20px`). Icons `16px`.
- Default: `#1D2129` on white. Hover / selected fill `#EAF6EE`. Selected text and icon `#0F6B3D` at weight 600.
- Directory parents (系统管理、客户管理) keep the same type size as leaves. Nested leaves indent; they do not shrink.
- Do not force a 13px menu font. Overflow menus use Level 3 elevation.

### 10. Workspace Tabs

- Bar height `40px`, canvas `#F4F6F8`, bottom border `#E5E6EB`. Sits directly under the header.
- Tab segments use radius `6px` and `body-md` (`14px / 20px`). Icons `16px` and **match the sidebar icon for that route** (看板 `LayoutDashboard`, 订单 `PackageSearch`, 账号 `Users`, 客服组 `UsersRound`, 客户 `Users`, 企业 `Building2`, 密钥 `KeyRound`). Do not paint every extra tab with a generic package icon.
- Inactive: white (`#FFFFFF`) fill, `#E5E6EB` border, `#1D2129` text. Hover fill `#EAF6EE`.
- Active: white fill, `#0F6B3D` border and text, weight 600. Do not tint every open tab green — green is the selected state only.
- Close control is a 16px hit target; hover uses error `#FFF2F0` / `#F5222D`.
- Overflow / context menus use `body-md` (`14px`) and Level 3 elevation. No 10px captions.
